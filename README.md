# APEX / Midnight Circuit

A dependency-free JavaScript 3D racing game, rendered with native WebGL.

Open `index.html` directly in a modern desktop browser, or run `npm start` and visit http://localhost:3000.

- Arrow up: accelerate
- Arrow down: brake / reverse
- Arrow left / right: steer
- Shift: nitro (recharges while released)
- Space: handbrake / sharper sliding turns
- P or Escape: pause
- R: restart

Complete three clockwise laps. Grass slows the car; stay on the circuit to register lap progress. Your best lap is saved locally in your browser. Requires WebGL and a keyboard.
